# ZTF User Guide

Complete documentation for the Zero Touch Framework.  The guide is split
into three parts for easier navigation.

## [Getting Started](getting-started.md)

Project structure, global configuration, and input file reference.
Start here if you are new to ZTF.

## [Configuration Reference](configuration-reference.md)

Interpolation, variables, `for_each`, lifecycle rules, data sources,
operations, outputs, commands, CLI flags, state management, dependency
resolution, plan/diff, schema negotiation, and example configurations.

## [Advanced Topics](advanced-topics.md)

Multi-environment workflows, logging and audit, custom Python functions
(`{fn.*}` tokens), PE-ops helpers, and Foundation Central helpers.

## [Entity Registry Migration](entity-registry-migration.md)

Reviewed entity aliases, corrected operation owners and lifecycle forms, the
Files limitation, and the optional one-time migration workflow.
